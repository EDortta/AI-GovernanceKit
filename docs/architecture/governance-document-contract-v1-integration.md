# Integração proposta — contrato documental v1

GovernanceKit é produtor de propostas, não aprovador. Deve apresentar fontes, lacunas e incertezas; usar LLM somente na descoberta e nunca produzir `approved` por inferência. Após revisão humana, o projeto inspecionado detém os Markdown canônicos. Mudança meramente documental, sem implementação do gerador.

A especificação em revisão é: https://github.com/EDortta/AI-Governance-Watchdog/blob/docs/governance-contract-v1/docs/architecture/governance-document-contract-v1.md
