# Integração da governança orientada por domínios

O GovernanceKit é responsável por analisar documentação e código e apresentar hipóteses de domínio/contrato, podendo utilizar LLM com referências, incertezas e revisão humana. É também orquestrador de sessões, gates e adoção; essa responsabilidade não é removida. A aprovação e a fonte canônica permanecem no projeto inspecionado. O AI-Governance-Watchdog realiza fiscalização determinística independente de LLM.
