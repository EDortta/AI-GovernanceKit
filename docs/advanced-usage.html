CLI reference

Advanced usage details

Every GovernanceKit command and parameter, including AI-Agents installation, per-instance identity, diagnostics, session resume, and deterministic context budgets.

Global syntax

governancekit [--root PATH] [--version] COMMAND [OPTIONS]
ParameterDescription
--root PATHSelects the repository to operate on. It is global, must precede the command, and defaults to the current directory.
--versionShows GovernanceKit, default AI-Agents, and project AI-Agents versions, including upgrade status.
-h, --helpShows global help or help for the selected command.

install-agents

# Fresh install
governancekit --root /project install-agents

# Update an existing installation
governancekit --root /project install-agents --upgrade
--ref REFAI-Agents tag, branch, or commit. Default: checksum-pinned v1.1.6.
--repo OWNER/REPOAlternative source repository. Default: EDortta/AI-Agents.
--forceOverwrites existing kit files.
--upgradeUpdates kit-owned files while preserving project-owned state.
--docs-onlyRefreshes managed documentation without touching AGENTS.md or tool adapters.
--install-awtInstalls the downloaded agent-worktree.sh helper onto PATH.
--trackKeeps kit documentation tracked in Git and saves the choice to .governancekit.
--no-trackKeeps kit documentation out of Git; mutually exclusive with --track.

configure and identity

The canonical file is .governancekit-identity.json. It is local, gitignored, and mode 0600. WORKSPACE.md is not required and does not satisfy the runtime identity gate.

governancekit --root /project configure \
  --operator-name "Name" --host-id "host-01" \
  --instance-path "/project" --sibling-path "/other-checkout" \
  --assigned-ports "3000,8000" --branch-ownership "feature/my-branch"
ParameterRequiredDescription
--set KEY=VALUENoFills a legacy placeholder; repeatable.
--operator-name NAMEYesHuman operator name.
--host-id IDYesStable machine or instance identifier.
--instance-path PATHYesAbsolute path of this checkout.
--sibling-path PATHNoAnother checkout that may contend for branches or resources.
--assigned-ports PORTSNoComma-separated ports reserved by this instance.
--branch-ownership BRANCHNoBranches operated by this instance.

Without identity flags, an interactive terminal prompts for missing fields. When flags are used, provide all required fields.

Validation and orientation

Command/parameterDescription
doctorValidates governance files, readiness, identity, secrets, state, and sibling-branch warnings.
doctor --jsonOutputs structured results for CI.
map --output PATHWrites the code map to a chosen path; default is docs/codemap.md.
map --allIncludes private, single-underscore Python symbols.
resumeShows active work, next step, handoff, identity, branch, and collision warnings.

Deterministic context

governancekit context inspect --task implementation --risk runtime --issue PATH --json
governancekit context build --task review --risk security --telemetry
governancekit context telemetry prune --manifest PATH
--task TYPESelects task contracts; default is implementation.
--risk RISKAdds a risk category; repeatable.
--issue PATHIncludes the active issue in context selection.
--manifest PATHUses an alternative context manifest.
--jsonOutputs context decisions and counts as JSON.
--telemetryOn build, appends metadata-only telemetry without content capture.
telemetry pruneDeletes telemetry older than the manifest retention policy.

Common sequences

# First setup
governancekit --root /project install-agents
governancekit --root /project configure
governancekit --root /project doctor

# Safe update
governancekit --root /project --version
governancekit --root /project install-agents --upgrade
governancekit --root /project doctor
